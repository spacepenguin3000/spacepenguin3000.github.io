AMT TOOLKIT v1.0 — INSTALLATION

This is a complete installable Progressive Web App (PWA), not a native App Store app.

To install on iPhone:
1. Upload ALL files and folders in this package, preserving their structure, to a static HTTPS website (e.g. Netlify Drop, Cloudflare Pages, GitHub Pages). Do not open index.html directly from Files: offline caching requires HTTPS or localhost.
2. Open the hosted URL in Safari on your iPhone.
3. Wait for the initial page to load with internet access.
4. Tap Share > Add to Home Screen > Add.
5. Launch AMT Toolkit from its Home Screen icon. After the initial successful load, it can run without internet access.

To test locally on a computer, serve the directory with `python3 -m http.server 8000` and visit http://localhost:8000 (service workers are allowed on localhost).
